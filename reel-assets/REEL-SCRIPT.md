## 📱 CapCut Mobile Steps (phone e)

1. CapCut → **New Project** → 5 ta image select (order: scene1 → scene5)
2. **Ratio → 9:16**
3. Prottekta image select kore **Canvas → Blur** → background auto blur hoye full screen fill korbe (eta cinematic look dey)
4. Prottek clip **2.5–5 sec** kore set koro (upore table onujayi)
5. Animation: prottek image e **Zoom In** (in) — Motion → Zoom In, 1.5s
6. **Transitions:** clip er majhe → Basic → **Pull in** ba **Flash**, 0.5s
7. **Text:** upore table er overlay gulo add koro — Font: bold white + black shadow, position: majh bhag
8. **Audio:** CapCut → Audio → Sounds → search **"aesthetic vibes"** ba **"cinematic whoosh"** — trending audio beshi reach dey. Volume 100%
9. **Export:** 1080p, 30fps
